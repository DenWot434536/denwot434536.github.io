Конфиденциальность

Что происходит с данными при использовании сайта «Ложка».

Данные на сайте

Сайт не содержит форм регистрации и не запрашивает имя, телефон или адрес электронной почты. Поиск и фильтрация рецептов работают в браузере; поисковые запросы не отправляются на сервер сайта.

Яндекс Метрика и Вебвизор

С вашего разрешения на сайте работает Яндекс Метрика — сервис статистики посещений. Он может использовать файлы cookie и собирать техническую информацию, например IP-адрес, сведения о браузере и устройстве, просмотренные страницы и переходы. Включённая в счётчике функция Вебвизор может записывать действия на странице, в том числе взаимодействие с полями ввода.

До вашего разрешения код Метрики не загружается. Вы можете отказаться или изменить решение через «Настройки аналитики» внизу любой страницы. При отказе дальнейшая отправка данных счётчиком прекращается; уже собранные данные обрабатываются в соответствии с политикой конфиденциальности Яндекса.

Хранение выбора и cookie

Ваш выбор сохраняется в локальном хранилище браузера на этом устройстве до изменения или очистки данных сайта. При согласии Яндекс Метрика может создавать файлы cookie. Ранее сохранённые cookie можно удалить в настройках браузера. Рекламные сети на сайте пока не подключены.

Хостинг и внешние ссылки

Сайт размещён на GitHub Pages. Хостинг может обрабатывать технические данные посетителей в соответствии со своей политикой конфиденциальности. При переходе на GitHub действуют правила этого сервиса. Чтобы задать вопрос через GitHub Issues, может потребоваться войти в свой аккаунт.
