Конфиденциальность

Что происходит с данными при использовании сайта «Ложка».

Данные на сайте

В текущей версии сайт не содержит форм регистрации и не запрашивает имя, телефон или адрес электронной почты. Поиск и фильтрация рецептов выполняются в браузере; поисковые запросы на наш сервер не отправляются.

Cookie и сторонние сервисы

В этой версии сайт самостоятельно не устанавливает файлы cookie и не подключает рекламные сети или системы аналитики. Если они появятся, информация на этой странице должна быть обновлена до их подключения.

Сайт размещён на GitHub Pages. Хостинг может обрабатывать технические данные посетителей в соответствии со своей политикой конфиденциальности.

Внешние ссылки

При переходе на GitHub действуют правила этого сервиса. Чтобы задать вопрос через GitHub Issues, может потребоваться войти в свой аккаунт.

Вопросы
