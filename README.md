# Ложка — сайт домашних рецептов

Статический сайт на HTML, CSS и JavaScript. Для работы не нужен сервер приложений или установка зависимостей. В репозитории сохранён существующий файл подтверждения Яндекса `yandex_f4b4cc3b4aabe9d9.html`.

## Запуск и изменение рецептов

Для локального просмотра запустите из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Главная страница, страницы рецептов и карта сайта уже собраны и могут размещаться на обычном статическом хостинге.

Источник рецептов — `data/recipes.json`. После изменения данных выполните:

```sh
python3 scripts/build.py
python3 -m unittest discover -s tests
node --test tests/test_analytics.js
```

Скрипт обновит `index.html`, страницы в `recipes/`, `about.html`, `privacy.html`, `sitemap.xml` и `robots.txt`. Дизайн находится в `assets/css/styles.css`, интерактивность — в `assets/js/main.js`. При переносе на другой домен измените `BASE_URL` в `scripts/build.py` и снова запустите сборку. Если изменится домен, заново проверьте подтверждение прав на сайт в Яндекс Вебмастере.

## Яндекс Метрика

На всех страницах настроен счётчик **113844022** из личного кабинета владельца. Метрика и Вебвизор загружаются только после явного разрешения посетителя; без JavaScript или после отказа визит не будет учтён этим счётчиком. Выбор хранится в `localStorage` браузера и доступен для изменения через «Настройки аналитики» в подвале сайта. При отзыве согласия отправляется команда остановки счётчика. Если хранилище недоступно, выбор действует только до перехода на другую страницу.

Код находится в `assets/js/analytics.js` и добавляется на каждую страницу через `scripts/build.py`. Для проверки после публикации откройте сайт, разрешите аналитику и проверьте счётчик в интерфейсе Метрики. Блокировщик рекламы или недоступность Яндекса могут помешать загрузке счётчика. Включение аналитики само по себе не означает прохождение модерации РСЯ.

В настройках счётчика предоставленный владельцем код включает Вебвизор. Если его отключить, синхронно обновите настройки в `assets/js/analytics.js` и сведения о конфиденциальности. Владелец сайта должен проверить применимые требования к уведомлениям, согласию и обработке данных.

- Для русскоязычной аудитории можно рассмотреть Рекламную сеть Яндекса. В [справке Яндекса](https://yandex.ru/support/direct/qanda/yan.html?lang=ru) указан платный хостинг; до подачи заявки проверьте актуальные требования и при необходимости перенесите сайт на подходящий хостинг и домен. Также ознакомьтесь с [ограничениями GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) для коммерческого использования.

Файлы шрифтов Manrope и Cormorant Garamond лежат в `assets/fonts`; их лицензии сохранены рядом.
